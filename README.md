## Course Details

**Service:** Amazon Relational Database Service (RDS)

Amazon RDS makes it easy to set up, operate, and scale a relational database deployment in the cloud. It manages routine database tasks such as patching, backups, and replication.

### Key concepts learned

- Understanding the benefits of managed relational databases over self-hosted databases.
- Creating and configuring RDS database instances running on Linux.
- Managing database security, accessibility, and network connectivity via VPCs and security groups.
- Performing automated backups, snapshots, and maintenance tasks.

### Learning outcome

I gained a foundational understanding of how Amazon RDS simplifies database administration, handles scaling and backups, and provides reliable relational database storage for cloud applications.
